# AI 小工具箱

用 AI 构建的轻量实用工具合集。所有工具以解决一个真实的小问题为目标，尽量做到无需注册、打开即用。

## Day 01：图片批量压缩器

一个完全在浏览器本地运行的图片压缩工具。

### 功能

- 拖拽或一次选择多张 JPG、PNG、WebP 图片
- 调整图片质量和最大边长
- 自动选择输出格式，也可指定 JPEG 或 WebP
- 显示逐张处理进度、压缩后体积和节省比例
- 支持单张下载与 ZIP 打包下载
- 图片不会上传到服务器
- 适配电脑和手机浏览器

### 使用

直接打开 `index.html` 即可使用。为了避免浏览器对本地文件的限制，也可以在目录中启动任意静态文件服务器。

例如：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

### 浏览器支持

推荐使用最新版 Chrome、Edge、Safari 或 Firefox。超大尺寸图片可能受到浏览器可用内存限制，此时可将“最大边长”设为 2560 px 或更低。

### 隐私

图片解码、缩放、编码和打包全部在当前浏览器中完成。页面没有上传接口，也不需要登录。
