# Day 11 · 口算题生成器

给家长用的口算题生成器：选难度和题量，一键生成一套可打印的口算卷（附答案页）。浏览器本地生成，不联网。

## 用法

```bash
python3 -m http.server 4173
# 访问 http://127.0.0.1:4173/tools/day-11-math-worksheet/
```

三个难度：十以内加减（一年级）、二十以内加减（二年级）、表内乘除 + 两位数加减（三年级）。题量 20/50/100。「打印 / 存 PDF」直接输出纸张版（答案页随卷）。

## 出题规则（不是随便出）

- 结果不超纲：十以内加减的和差也不超过十，二十以内同理；
- 减法不出负数；除法先定商再反推被除数，必整除、商在表内；
- 不出现 ×1、÷1 送分题；同套题不重复。

## 自检

浏览器控制台粘贴 `verify.js` 内容并回车，三个难度各 100 题、失败应为 0。

开发过程中当场发现并当场修复的真实问题：初版 300 题验证出 83 处错误——一/二年级各有 25 处「和超纲」（如 10+3=13、18+6=24），三年级 33 处（25÷6=4.17 这类不整除 18 处、商超表内 7 处、÷1 与 ×1 送分题 8 处）。修复后 300 题全过。
