# Day 15 · 图片转文字（免费在线提取）

截图、照片里的文字，选图识别、直接复制。识别在浏览器本地完成（Tesseract.js），图片不上传。适合提取：聊天截图、网页截图、文档截图里的文字。

## 用法

```bash
python3 -m http.server 4173
# 访问 http://127.0.0.1:4173/tools/day-15-image-to-text/
```

多选图片 → 开始识别 → 结果可编辑、一键复制。识别前自动做两项预处理：放大 2 倍 + 灰度化（小字号识别率的关键）；中文结果的字间空格自动压缩。

## 实测边界（如实报告）

| 场景 | 结果 |
| --- | --- |
| 清晰截图（20px 字） | 全对 |
| 压缩小字截图（13px、JPEG q50） | 中文全对；中英数字混排错 1-2 个标点（`：`→`;`），预处理后减半 |
| 模拟拍照（4° 倾斜 + 模糊 + 低对比） | 错 37 字，预处理后仍错 33 字——不可用 |

结论：**截图场景放心用；拍照歪斜模糊救不了**，请截屏或摆正重拍。手写、艺术字不适合。

## 已知处理

- 中文 OCR 结果常带字间空格（「识 别」），已自动压缩；
- 大图识别较慢（本地引擎），属正常等待。
