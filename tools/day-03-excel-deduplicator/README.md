# Day 03：Excel 重复数据清理工具

上传 Excel 文件，选择重复判断方式，预览将保留和移除的记录，然后下载清理后的副本。

## 功能

- 支持 `.xlsx`、`.xls` 和 `.csv` 文件
- 支持切换工作表
- 支持整行完全相同、单列或多列组合判断
- 支持保留第一条、保留最后一条或移除整组重复记录
- 可选择忽略英文大小写和首尾空格
- 实时显示原始记录、重复记录和清理后记录数
- 在导出前预览保留项和移除项
- 导出为新的 `.xlsx` 文件，原文件不受影响
- 全程在浏览器本地处理，不上传文件

## 使用

在仓库根目录启动静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/tools/day-03-excel-deduplicator/
```

## 数据说明

工具默认把第一行作为列标题，并处理当前选择工作表中标题之后的非空记录。导出副本会保留原工作簿中的其他工作表；当前工作表的数据会按预览结果重建。复杂公式、图表、合并单元格或特殊样式不保证完整保留，重要文件请先保留原始备份。

## 浏览器支持

推荐使用最新版 Chrome、Edge、Safari 或 Firefox。文件越大，读取和导出时占用的浏览器内存越多，建议将超大工作簿拆分处理。

## 第三方组件

Excel 解析和导出使用 SheetJS Community Edition 0.18.5。许可文件位于 `vendor/XLSX-LICENSE.txt`。
