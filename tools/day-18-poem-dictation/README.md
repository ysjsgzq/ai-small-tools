# Day 18 · 古诗默写卷生成器

选一首古诗，自动随机挖空生成默写卷，附答案页，直接打印。给娃听写前不用再手抄挖空半小时。浏览器本地生成，不联网、不上传。

## 功能

- 诗库：小学必背篇目 79 首，从一年级《咏鹅》到六年级《闻官军收河南河北》，含《忆江南》《清平乐·村居》两首词和《守株待兔》文言；支持按诗名 / 作者 / 诗句搜索（如搜「李白」「明月」「送别」）。
- 三档难度：简单（隔句挖 1 字）/ 中等（每句挖 1 字）/ 困难（每句挖 2 字）。
- 「重新出卷」每次随机，同一首诗可以反复出不同的卷子。
- 打印 / 保存 PDF：自动隐藏控件，卷面与答案分页，A4 直接打。

## 挖空规则（挖空的质量就是卷子的质量）

1. **按句定额**：挖空数由档位决定，不随机漂移——4 句诗三档恒定挖 2 / 4 / 8 个空，6 句诗 3 / 6 / 12。
2. **锚点保护**：禁止相邻两字都被挖。`床＿＿明月光` 这种连续空会毁掉默写锚点，把默写变成默背整句，一律不出现。
3. **同句重复字只挖首个**：《咏鹅》首行永远挖第一个「鹅」；「举头望明月」两个「头」类同理。
4. **单句上限**：挖空数不超过本句不同汉字数的一半，宁少勿滥。
5. 只挖汉字，不挖标点、不挖诗题；答案页整诗展示，红字标注挖空处。

## 使用

单文件静态页面，无依赖、无网络请求。

```bash
# 在仓库根目录启动本地服务
python3 -m http.server 4173
# 浏览器打开
# http://localhost:4173/tools/day-18-poem-dictation/
```

Windows / macOS / Linux 通用，也可直接双击 index.html 打开。

## 踩坑记录（真实发生）

第一版是「逐字随机挖」：概率一撒完事。测试当场暴露三个问题——同一首诗同一难度，20 张卷的挖空数在 **1~6 之间乱跳**（挖 1 个空的卷子没有任何默写价值）；困难档出现 **24 处一句挖 3+ 字**；更隐蔽的是 **30 处「＿＿」连续空**——「床＿＿明月光」把「明」「月」一起挖掉，孩子失去全部锚点，默写退化成默背整句。第二版改为按句定额分配 + 全档位禁止相邻挖空 + 重复字只挖首个，上述问题归零。

## 边界说明

- 诗库 79 首按人教版常见口径录入，个别篇目存在版本差异：《山行》「白云**生**处有人家」按人教版（生处）录入，部分读物作「深处」，默写以孩子课本为准。
- 挖空位置每次随机，若想要同一张卷子重复使用，用打印/保存 PDF 留底。
