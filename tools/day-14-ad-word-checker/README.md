# Day 14 · 文案极限词检测器

发文案之前，把广告法禁用的极限词（「最」「第一」「100%」「独家」等）先挑出来，红字标出位置。浏览器本地检测，文案不上传。

## 用法

```bash
python3 -m http.server 4173
# 访问 http://127.0.0.1:4173/tools/day-14-ad-word-checker/
```

粘贴朋友圈、商品文案、海报文字，一键检测。词库内置 41 个常见极限词。

## 两条防误伤规则

- **白名单短语先占位**：「最近」「第一时间」「第一次」这类日常用语不该被「最 / 第一」误伤；
- **长词优先、命中区占位**：「全网最低」命中后，单字「最」不在同一位置重复计数。

## 自检

测试文案埋 9 处真极限词 + 3 处陷阱（最近 / 第一时间 / 第一次）：初版朴素子串匹配命中 16 处（9 真 + 3 误伤 + 4 重复）；修复后 9/9 全中、0 误报、0 重复；纯陷阱干净文案 0 命中。

## 边界

只提示风险，不替你改词；单字「最」类以人工复核为准；词库为常见项节选，非法律意见。
