# Day 21 · 课程表生成器

把课表文字排成可打印的 A4 横向课程表：每行一节课（`周一 1 语文` 或 `周一 1 语文 教室302 王老师`），自动生成五列表格；同一班同一时段排了两门课会红框报错；支持连堂（`3-4`）与单双周（`6单`/`6双`）。浏览器本地生成，不联网、不上传。

## 格式

- 每行一节课：`星期 节次 课程名 [教室] [老师]`
- 星期：周一 / 星期一 / 礼拜一（纯数字有歧义——「1 2 数学」里的 1 是星期还是节次说不清——故意不收）
- 节次：`3` 单节、`3-4` 连堂、`6单`/`6双` 单双周
- 每天节数、下午起始节（标「午」）、班级标题可调

## 冲突规则

- 同一格已有课再排 → 报冲突（列出两行的行号与课名）
- 单双周同格 = 互补替代，不算冲突，格子标「单周/双周」
- 连堂跨格逐格登记，与其它课在任一格相撞都报

## 实测记录（2026-09-04，11/11 全部通过）

解析 8 项（标准行/连堂/单双周/别名/非法星期/非法节次/缺课程名/数字星期歧义拒绝）、同格冲突报错、单双周互补不报、A4 横向纸张 297mm（100% 缩放基准）。

## 踩坑记录（真实发生）

1. **纯数字星期别名是歧义坑**：`1 2 数学` 里的「1」当星期还是节次说不清。v1 收了数字别名，测试用例当场让它暴露——修复：故意不收纯数字星期，歧义输入直接报错比猜一个强。
2. **缩放模式下量纸张**：「适应屏幕」缩放（0.977）时量出 290mm 不是 297mm——测量要在 100% 缩放基准下做，测试脚本修正。

## 边界说明

- 只支持周一至周五（小学场景）；节次上限 10。
- 单双周只做了「一格一单一双」的互补，三课轮换（A单B双C全周）不支持。
