# Day 09 · 评论归类器

把一天的顾客评论按问题归类成一张表：先排除明显好评，再把事实按「出餐速度 / 口味 / 卫生 / 服务 / 包装 / 价格」六大类归堆，建议、情绪（无具体事实）、其他各自单独成区，每类附原始评论。归不进的不硬塞——「其他」超过三分之一时提示该修的是分类规则。

## 用法

```bash
python3 comment_classifier.py 评论.txt
```

评论从哪来（第一版不自动抓取、不碰账号，复制粘贴就是采集方案）：

- 外卖商家版 App（美团、饿了么）：评价管理里逐条复制；
- 商户后台网页版（点评管家等）：评价列表页框选复制一整页；
- 支持导出表格的后台：导出后把「评论内容」列复制出来。

整理成纯文本、一行一条即可。仅 Python 标准库，本地运行，也不会自动回复任何评论。

## 自检

```bash
python3 comment_classifier.py test_comments.txt
```

30 条测试评论，预期：问题 17（速度 5 / 口味 4 / 卫生 4 / 包装 2 / 服务 1 / 价格 1）、建议 5、情绪 1、好评 5、其他 2（占比 7%）。

已知误判（第一版的关键词方法边界，真实存在）：
- 「不咸不淡，刚好」被记成口味问题——关键词看得见「咸」，看不懂双重否定；
- 「上菜速度没得说，就是有点咸」整条进好评——夹在夸奖里的真问题被吞掉；
- 「价格涨得有点离谱」掉进其他——词表是「涨价」，评论写的是「涨得」。
