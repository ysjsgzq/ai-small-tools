# Day 09 · 评论归类器

把一天的顾客评论按问题归类成一张表：先排除明显好评，再把事实按「出餐速度 / 口味 / 卫生 / 服务 / 包装 / 价格」六大类归堆，建议、情绪（无具体事实）、其他各自单独成区，每类附原始评论。归不进的不硬塞——「其他」超过三分之一时提示该修的是分类规则。

## 用法

## 推荐入口：网页版（全平台）

浏览器打开 `index.html`（本地起个静态服务更稳）：

```bash
python3 -m http.server 4173
# 访问 http://127.0.0.1:4173/tools/day-09-comment-classifier/
```

粘贴文本或直接拖入评论区截图均可。识字在浏览器本地完成（Tesseract.js，首次联网加载引擎后走缓存），图片不上传任何服务器。Windows / macOS / Linux / 手机浏览器通用。实测一张 10 条评论的截图：识字 21 行、滤杂讯 11 行、10 条全部归类正确（含 OCR 字间空格压缩与结构化杂讯过滤，详见源码）。

## 命令行版

```bash
python3 comment_classifier.py 评论.txt        # 文本：一行一条（全平台）
python3 comment_classifier.py 评论区截图.png   # 截图（走 macOS 系统 Vision；其他系统请用网页版）
```

评论从哪来（不自动抓取、不碰账号，人自己动手，安全）：

- 外卖商家版 App（美团、饿了么）：评价管理里逐条复制；
- 商户后台网页版（点评管家等）：评价列表页框选复制一整页；
- 支持导出表格的后台：导出后把「评论内容」列复制出来；
- **直接截图**：很多评价页不让选中文字，长截屏/截图后直接喂给工具——macOS 用系统自带 Vision 离线识字（ocr.swift），自动滤掉用户名/时间等杂讯行；手机端也可用相册「提取文字」转文本。实测一张 10 条评论的截图：识字 21 行、滤杂讯 11 行、10 条全部归类正确（OCR 把「洒」认成「酒」，错字不影响归类）。

文本或截图均可。仅 Python 标准库 + 系统 OCR，本地离线运行，也不会自动回复任何评论。

## 自检

```bash
python3 comment_classifier.py test_comments.txt
```

30 条测试评论，预期：问题 18（速度 5 / 口味 4 / 卫生 4 / 包装 2 / 价格 2 / 服务 1）、建议 5、情绪 1、好评 5、其他 1（占比 3%）。

开发过程中当场发现并当场修复的三处误判：
- 「不咸不淡，刚好」曾误记为口味问题——「刚好」收入夸奖词表；整条只有夸奖、无转折的算好评；
- 「上菜速度没得说，就是有点咸」曾整条进好评——新增转折规则：先夸后转折的按转折后部分归类，夸奖不吞问题；
- 「价格涨得有点离谱」曾掉进其他——「涨价」放宽为「涨」。

修复后 30 条归类全部正确。关键词方法只会找字不会读句，真实评论仍有暴露空间。
