# Day 02：批量文件重命名工具

选择多个文件，按统一规则生成新名称，确认预览后将重命名副本打包下载。

## 功能

- 支持选择或拖入任意类型文件
- 自定义文件名前缀、分隔符、起始编号和编号位数
- 支持按选择顺序、文件名或文件大小排序
- 可选择是否保留原扩展名
- 实时展示“原文件名 → 新文件名”预览
- 校验非法字符、系统保留名称和重复文件名
- 将内容不变、名称已更新的副本打包为 ZIP 下载
- 全程在浏览器本地处理，不上传文件

## 为什么下载副本

普通网页没有权限直接批量修改电脑上的原文件名。为了避免覆盖或误改文件，本工具采用更安全的方式：保留原文件不变，将重命名后的副本放入 ZIP 压缩包供用户下载。

## 使用

在仓库根目录启动静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/tools/day-02-batch-renamer/
```

## 浏览器支持

推荐使用最新版 Chrome、Edge、Safari 或 Firefox。一次处理大量或超大文件时，ZIP 打包会占用浏览器内存，建议分批操作。

## 第三方组件

ZIP 打包使用 JSZip 3.10.1。许可文件位于 `vendor/JSZIP-LICENSE.md`。
