# Day 10 · PDF 合并器

把多个 PDF 按顺序合成一个文件，浏览器本地完成（pdf-lib），不上传任何服务器。Windows / macOS / Linux / 手机浏览器通用。

## 用法

```bash
python3 -m http.server 4173
# 访问 http://127.0.0.1:4173/tools/day-10-pdf-merger/
```

选择多个 PDF → 列表显示每个文件的页数 → ↑↓ 调整顺序（或按文件名排序）→ 合并并下载。加密或不兼容的文件会提示并跳过；引擎加载失败有显式提示（首次使用需联网加载一次 pdf-lib，之后走缓存）。

## 自检

`make_test_pdfs.py` 生成三个测试 PDF（报价单 1 页、合同 2 页、图纸清单 1 页，每页有唯一标记）。实测：上传后显示 1+2+1=4 页；合并输出 4 页且标记顺序与文件顺序一致；把「图纸清单」上移到顶后再合并，它排第一。文件只在本机浏览器里读写。

## 边界

只合并不改内容；扫描件合并后体积约为各文件之和；加密 PDF 不支持；超大文件受浏览器内存限制。
