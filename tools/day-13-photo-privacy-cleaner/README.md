# Day 13 · 照片隐私清理器

发照片之前，批量擦掉 EXIF 里的位置（GPS）、设备、拍摄时间等信息。浏览器本地重绘制导出，全程不上传。

## 用法

```bash
python3 -m http.server 4173
# 访问 http://127.0.0.1:4173/tools/day-13-photo-privacy-cleaner/
```

选多张 jpg/png → 列表标出哪些带 EXIF → 一键清理并打包 ZIP 下载。

## 原理与两条规矩

- 重绘制导出后，EXIF 自然不进入新文件——位置、设备信息全部留在本机；
- **格式跟进出**：PNG 进 PNG 出（保住透明），JPEG 进 JPEG 出（质量 0.92）；
- 竖拍方向不丢：依赖现代浏览器 `createImageBitmap` 自动按 EXIF 方向摆正。

## 自检

用 `make_test_photo.py` 给任意 JPEG 注入 GPS + 竖拍方向标签，再准备一张透明 PNG，一起清理后检查：输出无 `Exif`/`WGS-84` 字节、竖拍图尺寸已摆正（宽高互换）、PNG 仍为 PNG 且透明保留（角点 alpha=0）。实测三项全过。

## 开发过程中当场发现并当场修复

透明 PNG 被统一转成 JPEG 导出——透明背景变成纯黑（角点像素 0,0,0）。修复：输出格式跟随输入格式。另：预判的「EXIF 方向丢失」坑没来——现代浏览器自动处理了方向，手动再旋转反而会双重旋转，相关代码已删除。
