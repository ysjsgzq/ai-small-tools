# Day 04：客户跟进助手

把客户资料、沟通记录和最近联系时间整理成可执行的跟进队列。工具在浏览器本地运行，使用透明规则计算优先级，并生成下一次沟通草稿。

## 功能

- 客户列表新增、编辑、删除和本地自动保存
- 按优先级、最近联系、客户意向或名称排序，并支持搜索
- 规则辅助评分：意向、当前阶段和未联系天数共同决定跟进优先级
- 输出客户状态、意向、跟进节奏、下一步建议和可编辑话术
- 载入示例客户，方便首次体验
- CSV 导入与导出（字段：客户、公司、需求、预算、状态、反馈、最近联系、意向）
- 全程在浏览器本地处理，不上传客户数据

## 使用

在仓库根目录启动静态服务器：

```bash
python3 -m http.server 4173
```

打开：

```text
http://127.0.0.1:4173/tools/day-04-client-follow-up/
```

点击“载入示例”即可查看 5 条客户记录；也可以新增客户或导入 CSV。优先级是辅助判断，不会替代销售对客户关系、预算和时机的最终判断。

## 数据与隐私

客户记录只保存在当前浏览器的 `localStorage` 中。导出 CSV 会生成本地下载文件，清空浏览器站点数据会删除未导出的记录。请不要把真实客户敏感信息放入公共电脑。

## 浏览器支持

推荐使用最新版 Chrome、Edge、Safari 或 Firefox。工具无需构建步骤，无需第三方依赖。
