# 文档格式体检器

帮用户在提交标书、论文、申报材料之前，把「格式错了直接出局」的风险先过一遍。
背景与设计思路来自「AI帮我做」Day 08：内容写得好只是及格，格式漏一项可能直接废标。

## 核心原则

1. **只报告事实，不修改文档。** 改字号会牵动分页、目录、交叉引用，是否修改、如何修改由人决定，修改后可再复检。
2. **三状态，不许静默。** 每个检查项落进「符合 / 不符合 / 需人工确认」之一；「没查到」不等于「没问题」，查不到的一律标注出来，绝不略过。
3. **本地解析。** 文档和要求都不离开本机，不调用任何外部服务，不产生上传。
4. **定位到段落，不给页码。** 页码需要排版引擎算完分页才能得到，报告里如实说明这一限制。

## 工作流程

### 第一步：把格式要求拆成检查项

读取用户提供的格式要求原文（招标文件里的格式条款、学校模板说明、评审细则等），逐条拆成 `requirements.json`：

```json
{
  "requirements": [
    { "object": "正文", "attr": "east_asia_font", "expected": "仿宋_GB2312", "source": "招标文件 第三章 第2条" },
    { "object": "正文", "attr": "font_size_pt", "expected": "14", "source": "招标文件 第三章 第2条" },
    { "object": "正文", "attr": "line_spacing", "expected": "exact:28", "source": "招标文件 第三章 第2条" },
    { "object": "页面", "attr": "paper_size", "expected": "A4", "source": "招标文件 第五章" },
    { "object": "签章页", "attr": "manual_sign", "expected": "要求原件签字并加盖公章", "source": "招标文件 第八章", "checkable": false }
  ]
}
```

拆解规则：

- 每条检查项 = 四个字段：**检查对象（object）、目标属性（attr）、期望值（expected）、来源位置（source）**。
- 一句原话可能拆出多条：「仿宋_GB2312 四号，行距固定值 28 磅」= 字体、字号、行距三条。
- 来源位置必填——报告不只是说「错了」，还要让人能回到原文复核。
- 实体要求（打印效果、装订、签字盖章、密封）一律 `"checkable": false`，进「需人工确认」区。
- 语义拆不出来的要求保留原话，attr 用描述性名称并标 `"checkable": false`，不要猜。

attr 词表（脚本可核对）：

| attr | expected 写法 | 说明 |
| --- | --- | --- |
| `east_asia_font` / `ascii_font` | 字体名字符串 | 中文字体 / 西文字体 |
| `font_size_pt` | `"14"`（磅） | 四号=14、小四=12、三号=16 |
| `line_spacing` | `"exact:28"`（固定值28磅）或 `"multiple:1.5"` | 行距 |
| `margin_top_cm` 等 | `"2.54"`（厘米） | 上下左右页边距 |
| `paper_size` | `"A4"` | 纸张 |

### 第二步：运行体检脚本

```bash
python3 scripts/docx_format_check.py --doc 标书.docx --reqs requirements.json --out report.md
```

- 仅用 Python 3 标准库，无第三方依赖。
- 生效格式取值顺序：直接格式 > 段落样式链（含 basedOn 继承）> 文档默认（docDefaults）。样式表里埋的错误字体同样能查出。
- 旧版 `.doc` 需先另存为 `.docx`。

### 第三步：呈现报告

把 report.md 的三张表转述给用户：

- **不符合**：逐条给出「第几段、当前值、要求值、来源」，让用户能直接定位修改。
- **需人工确认**：附上要求原话，提醒按原文现场核对（打印、装订、签章等）。
- 结尾带上脚本报告中的「说明与限制」，不要隐瞒覆盖范围。

自检：用 `assets/test-bid.docx` + `assets/requirements.example.json` 跑一遍，预期结果为 3 项不符合、2 项需人工确认，其中第 3 段的宋体来自样式表继承（正是直接格式检查会漏掉的情形）。

## 边界（主动告诉用户，不装作能查）

- 页眉页脚、表格内部、目录域、修订记录：未覆盖。
- 打印效果、装订顺序、手签与印章原件：机器无法检查，只能提醒。
- 页码定位：给不出，只到段落。
