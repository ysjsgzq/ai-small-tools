# Day 16 · 加班费计算器

按法定口径算清三类加班费：工作日延时 1.5 倍、休息日未补休 2 倍、法定节假日另行支付 3 倍；同时对照「按每月 30 天折算」的常见算法，直观看到两种口径的差额。

## 规则依据

- 倍率：《劳动法》第四十四条（工作日延时不低于 150%、休息日未补休不低于 200%、法定节假日不低于 300%）。
- 月计薪天数 21.75 天：劳社部发〔2008〕3 号《关于职工全年月平均工作时间和工资折算问题的通知》，(365 − 104) ÷ 12 ＝ 21.75；时薪 ＝ 月工资 ÷ 21.75 ÷ 8。
- 法定节假日为带薪假日，加班费系「另行支付」的 300%，不得以补休替代；休息日优先补休，不能补休才付 200%。

## 使用

单文件静态页面，无任何依赖与网络请求，数据全程留在浏览器本地。

```bash
# 在仓库根目录启动本地服务
python3 -m http.server 4173
# 浏览器打开
# http://localhost:4173/tools/day-16-overtime-pay-calculator/
```

Windows / macOS / Linux 通用，也可直接双击 index.html 打开。

## 边界说明

- 加班费基数按「应发工资」口径（含奖金、津贴、补贴），不含报销款；各地仲裁口径存在差异，以当地规定为准。
- 经批准实行不定时工作制的岗位一般不适用加班费（法定节假日除外，部分地区支持）。
- 本工具用于估算与核对，不构成法律意见。
