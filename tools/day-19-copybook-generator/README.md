# Day 19 · 字帖生成器

输入生字自动排田字格描红字帖；拼音按四线三格排布，字母占格符合教学规范；字母 / 数字可大小写成对出帖。调好直接打印 A4。浏览器本地生成，不联网、不上传。

## 功能

- **田字格生字**：输入任意汉字（自动去重可选），每行首字深色示范、其余浅灰描红，也支持全部描红 / 只出空格；格宽、每行格数可调。
- **拼音四线三格**：内置声母表（23）/ 韵母表（24）/ 整体认读音节（16），也可输入自定义拼音串；字母按教学规范占格。
- **字母 / 数字**：大写、小写、大小写成对（Aa…Zz）、数字 0-9，一键填充。
- 打印 / 保存 PDF：自动隐藏设置区，A4 纵向，格线颜色随打印输出（`print-color-adjust: exact`）。

## 占格规则（拼音教学规范）

| 类别 | 字母 | 本工具实测（格高 26px，线 0/26/52/78） |
| --- | --- | --- |
| 上中格 | b p f d t l h k ü | b 墨迹 16~50，越过第 2 线入上格 ✅ |
| 中格 | a o e i u c m n r s v w x z | a 30~50、m 29~50，落在中格 ✅ |
| 中下格 | g q y | g 底 57、q 底 57，越过第 3 线入下格 ✅ |
| 上中下三格 | j | j 19~61，三格贯穿 ✅ |

## 踩坑记录（真实发生）

1. **v1 字母全瘫在中格**：四个字母渲染位置完全相同——b 没升上格、g 没降下格、j 没贯穿三格。拼音教学里占格错误是家长一眼能识破的硬伤。
2. **v2 按 CSS 行盒推算 baseline，量出来落在 62 而不是第 3 线 52**：行盒的半行距计算依赖字体内部度量，解析算不准。v3 改为渲染后插入零宽探针实测 baseline，再整体平移到第 3 线——对任意格高都成立。
3. **测试期望值又数错了**：断言「12 个字每行 12 格应为 1 行」，实际输入是 13 个字（人肉数数三连错，前两次见 Day 17）。工具全对，期望值修正后通过。
4. **`page-break-inside` 在现代 Chrome 里被序列化为 `break-inside`**，测试脚本按旧属性名匹配失败——按序列化实际值断言。

## 边界说明

- 控笔练习（线条图形训练）不在范围内——那需要美术设计，不是排版能解决的，如实不做。
- 汉字用系统楷体栈（Kaiti SC / STKaiti / KaiTi），个别系统无楷体时回退衬线体。
- 若浏览器打印预览里格线消失，请在打印设置勾选「背景图形」。
