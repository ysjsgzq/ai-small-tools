# Day 12 · AA 分账计算器

聚餐多人各付了一部分，算清「谁该转谁多少钱」，并给出**最少转账方案**。浏览器本地计算，不联网。

## 用法

```bash
python3 -m http.server 4173
# 访问 http://127.0.0.1:4173/tools/day-12-aa-splitter/
```

输入每人已付金额（照着微信/支付宝账单填），一键输出转账清单。核心逻辑：先把每人「已付 − 应付」算成净额，再用贪心配对（最大应收 vs 最大应付）求最少转账。

## 两条金额铁律

- 全程以「分」（整数）计算，杜绝浮点幽灵小数（0.1 + 0.2 = 0.30000000000000004 这种）；
- 人均除不尽时按最大余数法：人均取整到分，余数由前 r 人各多担 1 分——每一分钱都有去处。

## 自检

控制台粘贴 `verify.js` 内容并回车：4 个案例（含 0.1+0.2 浮点案例与七人除不尽案例）+ 随机 100 组应全部通过（转账后人人两清、金额均为整数分、笔数 ≤ 人数−1）。实测 100 组平均 5.1 人场景，朴素两两互转平均 12.4 笔，贪心算法 4.1 笔。

开发过程中当场发现并当场修复：初版浮点计算产生 0.30000000000000004 与 ¥163.35714285714286 两个真实翻车现场。
