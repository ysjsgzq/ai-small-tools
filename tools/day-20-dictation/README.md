# Day 20 · 生字听写工具

输入今晚的词表，点「开始听写」，浏览器自动语音报词：每词可读 1–5 遍、间隔 3–30 秒留书写时间、语速可调，支持随机顺序。听完逐词核对标记对错，错词可以只重听错词。全程浏览器本地运行（语音用系统内置合成引擎），不联网、不上传。

## 功能

- 词表：空格/逗号/顿号/换行混合分隔，自动去重；附一年级常用词预设。
- 语音：Web Speech API（系统内置中文语音）；**音色下拉列出当前设备全部中文音色**（本机 18 个：婷婷、Eddy、Flo、Reed、Shelley 等），可逐个试听选择，localStorage 记忆；缺失时提示换浏览器。
- 语速默认 0.7x（范围 0.4–1.2x）、**音调 0.7–1.3 可调**、**遍间隔 0.3–3 秒可调**（默认 1 秒，读两遍之间更从容）。
- 听写控制：暂停/继续、重播本词、上一词/下一词；报词时默认不显示字（防「看写」），可开启显示。
- **倒计时滴声**：词间隔最后 3 秒每秒一声「滴」，音调逐秒升高（660/784/932Hz，Web Audio 本地合成，零音频资源），可开关——孩子不用盯着屏幕等下一个词。
- 闭环：听写结束 → 核对表逐词标记 ✓/✗ → 「只重听错词」一轮错词重听。

## 踩坑记录（真实发生）

1. **快速切词旧词追读**：每词读第二遍前有 600ms 重播定时器，点「下一词/重播」只清了倒计时 interval，没清这个定时器——上一个词会追着多读一轮，mock 语音的时间戳日志当场暴露（火车读了 4 遍）。修复：报词代际令牌（speakGen），每次开始报新词递增，旧代的定时器与回调全部作废。
2. **语音列表异步加载**：`getVoices()` 在部分浏览器首次调用返回空列表，需监听 `onvoiceschanged` 兜底（本机 Chrome 同步就绪，未自然暴露，代码预防）。
3. **测试期望值第四次写错**：词表是「高山」，断言字符串手写成「大山」——功能全对，期望值错。人肉翻车四连（前三次见 Day 17、Day 19）。

## 边界说明

- 语音依赖浏览器内置合成引擎：macOS/iOS 的 Safari、桌面 Chrome/Edge 均有中文语音；部分安卓 WebView 内核无中文语音，工具会显示提示。
- 报词发音为合成语音（婷婷/慧慧等），清晰度足以听写，与真人情感朗读有别。
