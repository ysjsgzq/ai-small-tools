原理与边界

  • 算法自写、零依赖：先按行做最长公共子序列（LCS）找出改动区，再在改动的行内按「中文字 / 英文词」为单元做第二次 LCS，得到字级差异。
  • 英文按整词比对（1.2.3 是一个单元），不会把一个单词拆成字母产生噪音。
  • 段落移动会被显示为「一删一增」——diff 判断内容增删，不追踪位置移动。
  • 超长文本（单侧超过 4000 行）建议分段对比；本地计算，关闭页面即忘。
