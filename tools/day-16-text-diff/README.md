# Day 16 · 文本对比工具

两版文字贴进来，增、删、改逐字标色。适合合同改版、论文修改、方案往返——对方说「就改了几个地方」，到底改了哪几个，一眼看清。全程浏览器本地计算，不联网、不上传。

## 原理（算法自写、零依赖）

- **两级对比**：先按行做最长公共子序列（LCS）找出改动区，再在改动的行内按「中文字 / 英文词」为单元做第二次 LCS，得到字级差异。
- **英文按整词比对**（`1.2.3` 是一个单元），不会把单词拆成字母产生噪音。
- 相邻的删行与增行自动配对成「改」行，行内红删绿增；配不上的单独标「删」「增」，并带原/新行号。
- 汇总统计：修改行数、新增行数、删除行数、字/词级新增删除数；一键复制纯文本差异清单（`[修改] 第2行：… → …`），可直接发给对方。

## 使用

单文件静态页面，无依赖、无网络请求。

```bash
# 在仓库根目录启动本地服务
python3 -m http.server 4173
# 浏览器打开
# http://localhost:4173/tools/day-16-text-diff/
```

Windows / macOS / Linux 通用，也可直接双击 index.html 打开。

## 踩坑记录（真实发生）

1. **v1 整篇逐字比对内存爆炸**：7200×7200 token 的 LCS 矩阵直接超限报错——改为两级对比（先行级再行内），300 行大文本 300ms 出结果。
2. **空文本被当成一行空行**：`''.split('\n')` 得到 `['']`，「空 → 你好」被显示成「改」——空文本按零行处理，复测通过。

## 边界说明

- 段落移动会被显示为「一删一增」——diff 判断内容增删，不追踪位置移动。
- 单侧超过 4000 行建议分段对比。
- 本地计算，关闭页面即忘。
